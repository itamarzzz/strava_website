# STRAVA WEBSITE

A static educational web application inspired by Strava's athlete dashboard, built with vanilla HTML, CSS, and JavaScript.

## Features
- 3-column Strava web dashboard layout (Profile & Weekly Goal, Activity Feed, Challenges & Segment Leaderboard)
- Interactive sport filtering (`Dashboard`, `Runs`, `Rides`, `Training`) and live search
- Interactive Kudos reactions and comment threads (persisted in `localStorage`)
- **Log Activity** modal that computes pace/speed dynamically and updates weekly mileage progress

## Deploying to GitHub Pages
1. Extract `STRAVA WEBSITE.zip` and create a new public repository on GitHub (e.g., `strava-website`).
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` directly into the root of the repository.
3. Go to **Settings → Pages**, choose **Deploy from a branch**, select **`main`** and **`/ (root)`**, and click **Save**.
